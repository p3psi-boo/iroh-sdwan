# 文档索引

本文档面向部署、运维和开发 `ironet` 的人员。命令示例以 Debian/Linux 路径为准；使用源码或 NixOS 时可按实际二进制和配置路径替换。

| 文档 | 内容 | 适用对象 |
| --- | --- | --- |
| [快速开始](快速开始.md) | 两节点静态拓扑、初始化、启动与连通性检查 | 首次部署人员 |
| [配置参考](配置参考.md) | TOML 字段、校验规则、动态 mesh、relay、DERP 与 FEC | 配置维护人员 |
| [运行与运维](运行与运维.md) | systemd、状态查询、监控、配置更新、备份与排障 | 运维人员 |
| [开发与测试](开发与测试.md) | 开发环境、检查命令、集成测试、打包和发布 | 开发与发布人员 |
| [性能验证](性能验证.md) | 数据面微基准、p2–p6 WAN 矩阵和验收指标 | 性能与网络测试人员 |
| [架构与路由模型](架构与路由模型.md) | 数据面、选路、容量测量与转发边界 | 需要理解运行行为的人员 |
| [扩展开发](扩展开发.md) | 控制 API、事件游标、期望状态和 Rust SDK | 扩展与控制器开发人员 |
| [Ironet Protocol V1](protocol-v1.md) | V1 会话认证、统一 envelope、特性协商与稳定性规则 | 协议实现与互操作人员 |

配置样例位于 [`config/example.toml`](../config/example.toml)。该文件中的值均为示例，部署前应替换网络 ID、身份文件路径、地址、前缀和 peer 信息。
