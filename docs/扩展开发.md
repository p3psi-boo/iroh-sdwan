# 扩展开发

Ironet 的扩展边界是“稳定控制面、封闭数据面”。扩展通过版本化 Unix Socket API
声明期望状态和订阅事件，不加载进 `ironetd`，也不接触 FlowRouter、QUIC 队列或内部锁。

## Rust SDK

仓库中的 `ironet-extension-sdk` 是轻量 SDK，仅依赖 Tokio、Serde 和 JSON：

```toml
[dependencies]
ironet-extension-sdk = { path = "../ironet/crates/ironet-extension-sdk" }
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
```

完整程序见 [`examples/extension_controller.rs`](../examples/extension_controller.rs)。运行前提供
路由所有者的 EndpointId：

```bash
IRONET_ROUTE_ENDPOINT=ENDPOINT_ID \
  nix develop -c cargo run --example extension_controller
```

生产扩展应在启动和断线重连后先调用 `get_capabilities`，不要根据 daemon 构建版本猜测
接口能力。

## API 方法

所有请求和响应都是单行 JSON，携带 `version` 和 `id`。当前公开接口：

| 方法 | 权限 | 作用 |
|---|---|---|
| `get_capabilities` | socket 读权限 | 返回 API 版本、能力和资源限制 |
| `get_snapshot` | socket 读权限 | 返回运行状态、期望路由和当前事件游标 |
| `watch_events` | socket 读权限 | 从游标开始订阅有序事件 |
| `list_routes` | socket 读权限 | 查询仍在租约期内的扩展路由 |
| `apply_routes` | root/daemon UID | 原子创建或更新期望路由 |
| `delete_routes` | root/daemon UID | 原子删除期望路由 |

旧的 `snapshot/status/peers/health/ping/trace/reload` 运维接口继续使用同一传输，但不是
扩展 SDK 的稳定类型表面。

## 期望路由

每条扩展路由以 `(owner, name)` 唯一标识：

```json
{
  "version": 1,
  "id": 7,
  "method": "apply_routes",
  "routes": [{
    "api_version": 1,
    "name": "office",
    "owner": "example.com/ipam",
    "revision": 42,
    "ttl_seconds": 300,
    "spec": {
      "endpoint_id": "ENDPOINT_ID",
      "prefixes": ["10.30.0.0/16"]
    }
  }],
  "dry_run": false,
  "idempotency_key": "ipam-office-r42"
}
```

- `owner` 使用稳定命名空间，不表示网络中的路由 EndpointId；
- 同一路由更新时 `revision` 必须严格递增；完全相同的状态视为 unchanged；
- `idempotency_key` 重放返回原结果，用不同参数复用同一 key 会失败；
- `dry_run` 执行完整解析和冲突校验，但不落盘、不 reload；
- `ttl_seconds` 最大 30 天；租约到期后守护进程删除路由、reload 并发布
  `route.expired`；
- 状态保存在 `identity_file` 同目录的 `extensions.toml`，与人工维护的
  `routes.toml` 分离，最终由同一配置校验器检查前缀冲突。

## 事件与重同步

`watch_events` 接受可选 `after_cursor`。未提供游标时从当前时刻开始。服务先返回：

```json
{
  "event": "result",
  "result": {"current_cursor": 18, "oldest_cursor": 1}
}
```

随后持续发送 `extension_event`。当前事件包括 `daemon.ready`、`route.applied`、
`route.deleted` 和 `route.expired`。

事件日志固定保留 1024 条，生产者从不等待消费者。游标早于保留窗口时返回
`cursor_expired`；扩展必须重新调用 `get_snapshot`，应用其中的完整状态，然后从
`event_cursor` 恢复订阅。这是唯一的慢消费者恢复路径。

## 稳定性边界

- 稳定：SDK DTO、方法名、错误码、游标语义、owner/revision/TTL 语义；
- 前向兼容：snapshot 中未知 JSON 字段；扩展只解析自己使用的字段；
- 非稳定：`ironet` 主 crate 中除 extension SDK 外的 Rust 类型；
- 扩展进程异常、阻塞或退出不会阻塞数据包转发；
- 核心 `config.toml` 继续拒绝未知字段，不作为插件配置容器。
