18. 公平性与 50/100 Mbit/s 家庭上行场景已经形成可复现闭环。矩阵新增 `IRONET_V2_MATRIX_FAIRNESS_SECONDS`、`IRONET_V2_MATRIX_FAIRNESS_PER_STREAM_MBIT`，aggregate 输出 Jain、spread、最大偏差以及共享 TUN admission 的精确丢弃 records/bytes。首轮 `target/v2-netns-fairness-home-100d50u-v1` 的 4 路各 20 Mbit/s UDP 为 Jain 0.99985、spread 3.03%，但 TCP overlay/underlay 仅 9.53/46.46 Mbit/s。后续结论如下：
    - **纯 backpressure 已被实测否决**：停止读取 packet TUN 只会把不可见积压移入内核/TUN 队列，最终 iperf 控制报文和 FIN 被旧 Bulk 阻塞，出现约 7.15 Mbit/s 服务端结果、客户端 JSON 失败。packet TUN 不能向内层 TCP 提供 transport backpressure。
    - **最终 admission 语义是“持续读取 + 语义优先 + 可观测过载丢弃”**：无竞争路径保留原始 GSO record；拥塞时仅对真实 GSO record 先 `gso_split` 再逐段准入，ICMP/ACK/FIN 继续进入独立 priority lane，普通流量在共享字节预算边界有界丢弃。TUN 自动安装 `fq_codel limit 1024 memory_limit 1MiB ecn`，`tx_queue_len=128`；过激的 16-record 队列曾得到 5.45 Mbit/s、ping 丢包 14.7%，已经否决。共享边界 records/bytes 已进入 status、Prometheus、单场景 summary 和矩阵 aggregate。
    - **控制器根因修复**：loss-tolerant BBR3 在 Startup/ProbeBW-Up 获得 4× 相对、至少 20 ms 的 queue-guard 探测余量，避免家庭整形器让带宽估计永久卡在局部低点；Drain/Cruise 与 `loss_is_congestion=true` 保持严格。动态 cwnd floor 用“当前已证明需求 × minRTT × cwnd gain”自动计算，16 KiB 量化、8 MiB 封顶，并由排队、CPU、app-limited、路径可靠性护栏即时撤销。一次额外的跨样本 peak-demand 保持实验 `v14` 使 60 s overlay 从 `v13` 的 31.41 降到 30.02 Mbit/s，已回滚，不进入实现。
    - **FEC 不再被瞬时 burst 固定**：低绝对丢包、wasted parity 高时，Repair 在 `max(8×minRTT, 200 ms)` 内有已证明命中即可关闭 FEC；证明形成前先从 8+1 降到 16+1。`v13` 的发送侧只出现 1 次 8+1、1 次 16+1，随后 18 次为 off，说明稀疏过渡与退出都真实发生。
    - **当前长期证据**：`target/v2-netns-fairness-home-100d50u-v13-sparse-fec-60s` 为 60 s TCP + 15 s UDP fairness、双端 perf。underlay 46.33 Mbit/s，overlay 31.41 Mbit/s，ratio 67.79%，末 5 s 28.94 Mbit/s；overlay ping p95 26.0 ms，低于 underlay 69.1 ms；4 流 Jain 0.999996、spread 0.504%；perf lost 0/0，SVG SHA256 为 A `1d82344a…1dd9`、B `b6e10257…dd3`。最终 admission 共 80,803 records/105,817,571 bytes，但时间戳证明 TCP 60 s 内只增长到 128 records/约 5.94 MiB，绝大多数发生在随后 80 Mbit/s offered-load 的 UDP fairness 阶段，不能再把总数误判成 TCP 吞吐主因。
    - **控制器对齐设施已补齐，吞吐缺口保留为证据驱动问题**：tap schema 5 新增实际 cwnd 与本轮 adaptive floor；profile 把 active side 每秒 tap 与 iperf interval 对齐为 `controller_interval_series`，并输出去除 app-limited/空队列样本后的相关性、末 5 样本均值，矩阵 aggregate 同步收录。`target/v2-netns-fairness-home-100d50u-v16-controller-steady` 20 个稳态样本中，末 5 样本 overlay 30.82 Mbit/s、controller bw 3.86 MiB/s、cwnd 192 KiB、floor 188.8 KiB、packet-train queue 292.6 KiB；overlay 与 bw/cwnd/floor 相关性为 0.074/-0.453/-0.793。它证明 floor 已实际生效但不是吞吐充分条件，也不支持再叠加 cwnd 启发式；BBR 带宽模型问题留待迁移场景取得 state transition 证据后处理。

## 6. 坑与约束
